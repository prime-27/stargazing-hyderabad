# stargazinghyderabad.com

A static site, a guide to stargazing around Hyderabad, hosted on GitHub Pages.

- `index.html`, `styles.css`, `app.js`: the page. Tonight's moon, moon-free hours, darkest weekends and meteor-shower moonlight are calculated in the visitor's browser for Hyderabad (IST).
- `CNAME`: the custom domain GitHub Pages serves.
- `404.html`: the not-found page.

No build step: edit the files and push to `main` to publish.
